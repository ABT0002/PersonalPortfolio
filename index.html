Projects

Stratsim - F1 Race Strategy Simulator

Built a race-data processing pipeline using Python, Pandas, and OpenF1 telemetry to reconstruct driver race states across 53 laps of the 2025 Italian Grand Prix. Implemented PIT vs. STAY strategy logic using tire age, compound, and historical pit-stop duration. Processed 976 lap records, 39 stints, and 19 pit stops to analyze race strategy decisions.

Technologies Used: Python, Pandas, OpenF1

BMP Image Processing Tool

Developed a command-line BMP image editor in C using binary file parsing and pixel manipulation. Implemented image transformations including inversion, grayscale conversion, and horizontal flipping while managing memory and pixel data directly.

Technologies Used: C, File I/O, Memory Management
